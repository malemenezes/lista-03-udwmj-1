# lista-03-udwmj-1
Lista de Exercícios III

Repositório da Lista de Exercícios III da disciplina Usabilidade, Desenvolvimento Web, Mobile e Jogos, ministrada pelo Professor Daniel Henrique Matos de Paiva.

📋 Sobre a atividade

Esta lista de exercícios deve ser realizada em equipes de até 5 alunos, entregue no prazo proposto, com entregas individuais.

📝 Exercícios
1. Área do Círculo

Algoritmo em HTML, CSS e JS que lê o raio de um círculo e calcula sua área.

Fórmula: área = π * raio²
Arquivos: pratica03exercicio04.html, pratica03exercicio04.css, pratica03exercicio04.js
Observação: utilizar Math.PI
2. Volume da Esfera

Algoritmo em HTML, CSS e JS que lê o raio de uma esfera e calcula seu volume.

Fórmula: volume = 4/3 * π * raio³
Arquivos: pratica03exercicio05.html, pratica03exercicio05.css, pratica03exercicio05.js
Observação: utilizar Math.PI
3. Juros Compostos

Algoritmo em HTML, CSS e JS para cálculo de juros compostos, a partir do capital inicial, da taxa de juros e do prazo (tempo) de investimento informados pelo usuário. O algoritmo calcula o montante, considerando que taxa e prazo estão na mesma unidade de tempo.

Fórmula: M = C * (1 + i)^t, onde:
M = montante
C = capital inicial
i = taxa de juros
t = tempo
Arquivos: pratica03exercicio06.html, pratica03exercicio06.css, pratica03exercicio06.js
4. Publicação no GitHub

Subir o projeto para o GitHub pessoal e enviar o link na plataforma da disciplina.
