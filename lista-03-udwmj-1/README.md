# Lista 03 - UDWMJ

Exercícios da Lista de Exercícios III da disciplina **Usabilidade, Desenvolvimento Web, Mobile e Jogos (UDWMJ)**.

**Professor:** Daniel Henrique Matos de Paiva

## Exercícios

### Exercício 04 - Área do Círculo

Programa desenvolvido com HTML, CSS e JavaScript para calcular a área de um círculo a partir do raio informado pelo usuário.

Fórmula utilizada:

```text
A = π × r²
```

### Exercício 05 - Volume da Esfera

Programa desenvolvido com HTML, CSS e JavaScript para calcular o volume de uma esfera a partir do raio informado pelo usuário.

Fórmula utilizada:

```text
V = 4/3 × π × r³
```

### Exercício 06 - Juros Compostos

Programa desenvolvido com HTML, CSS e JavaScript para calcular o montante de um investimento utilizando juros compostos.

Fórmula utilizada:

```text
M = C × (1 + i)ᵗ
```

Onde:

* M = montante
* C = capital inicial
* i = taxa de juros
* t = tempo
